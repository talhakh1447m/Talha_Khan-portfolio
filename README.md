# Talha Khan — 3D Digital Portfolio

A dark, cinematic desktop-style portfolio inspired by the supplied reference image.

## Features
- Draggable macOS-style portfolio windows
- About, Projects, Assignments, My Work, Skills, Experience, Education, Certificates, Contact and Resume sections
- Project search and category filters
- Responsive mobile layout
- Real project/assignment/work thumbnails
- GitHub link integration
- Resume download slot at `public/resume.pdf`

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build
```bash
npm run build
```

Replace `public/resume.pdf` with your latest resume PDF when ready. Replace the placeholder `#` live/demo links in `src/main.jsx` with your actual project URLs.
